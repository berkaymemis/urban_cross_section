# 🖼️ `icons/` — UrbanCrossSection İkonları

Bu dizin, eklentinin QGIS araç çubuğu, menüsü ve QGIS Hub için yüksek çözünürlüklü ikonlarını içerir.

## Dosyalar
* `icon.png` — 48x48 piksel eklenti menü ve araç çubuğu ikonu.
* `icon_512.png` — 512x512 piksel resmi QGIS Plugin Hub vitrin ikonu.
* `generate_icons.py` — İkonları QPainter ile vektörel olarak üreten betik.
