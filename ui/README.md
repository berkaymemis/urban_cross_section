# 🎨 `ui/` — UrbanCrossSection Arayüz Katmanı

Bu dizin, eklentinin görsel arayüzünü ve mimari çizim tuvalini içerir.

## Modüller
* `canvas_widget.py` — `QPainter` tabanlı, 300 DPI donanım hızlandırmalı canlı 2D kesit çizim tuvali.
* `main_dialog.py` — Şerit yönetimi, hazır MPYY şablonları, bina gabarileri, SVG/PNG export ve QGIS Print Layout butonlarını barındıran ana pencere.
