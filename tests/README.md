# 🧪 `tests/` — UrbanCrossSection Test Katmanı

Bu dizin, hem saf Python birim testlerini hem de headless PyQGIS duman testlerini içerir.

## Dosyalar
* `test_core_sections.py` — Saf Python birim testleri (elemanlar, 9 hazır şablon, mimari SVG üretimi, doğrulama).
* `qgis_smoke.py` — QGIS 3.44 (Qt5) ve QGIS 4.2 (Qt6) dual-runtime ortamlarında eklenti yükleme, arayüz, haritada dik kesit hattı ve Print Layout testleri.
